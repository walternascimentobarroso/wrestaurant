# Estrutura Base do Projeto

Gerado em: 26/06/2026

## Tipo de sistema

Fullstack (frontend + backend)

## Stack tecnológica

### Frontend

Next.js

### Backend

FastAPI (Python)

## Banco de dados

Sim — PostgreSQL para persistência de dados da aplicação.

## Containerização

### Docker

Sim — containerização do frontend, backend e demais serviços para ambientes consistentes entre desenvolvimento e produção.

### Docker Compose

Sim — orquestração dos serviços: frontend (Next.js), backend (FastAPI) e banco de dados (PostgreSQL).

## Resumo executivo

Projeto fullstack com frontend em Next.js e backend em FastAPI, utilizando PostgreSQL como banco de dados relacional. A infraestrutura local e de deploy será containerizada com Docker, com orquestração via Docker Compose para subir e gerenciar os três serviços principais: app web, API e banco de dados.
